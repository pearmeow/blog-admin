Blog Admin Page
---------------

Blog admin page made with [React](https://react.dev).

Features
--------

- [x] Login page
- [x] Register page with code to register
- [x] Create article
- [x] Edit article
- [x] Delete article
- [x] Delete comments on articles
- [x] No styling

How to use this project
-----------------------

Visit the live link [here](https://pearmeow-blog-admin.netlify.app/)! You won't be able to do anything without an author code or login though...
